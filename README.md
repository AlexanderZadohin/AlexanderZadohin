## 🧩 Что люблю автоматизировать (идеи для репо)

- `terraform-*` — инфраструктура: сети, VM, k8s, базы, секреты  
- `ansible-*` — роли: nginx, docker, hardening, users, backups  
- `k8s-*` / `helm-*` — чарты, манифесты, GitOps-подход  
- `ci-cd-*` — пайплайны: сборка, тесты, деплой, версии, релизы  
- `monitoring-*` — Prometheus/Grafana/Alertmanager, логирование и алерты  
- `fullstack-*` — .NET API + React UI + БД + деплой в контейнерах
